# 封面语言替换 / Cover localization

中文：把已确认成图作为编辑目标，逐条列出新文案。专有名词保持原拼写，不要因换语言重做人物或背景。

English: Edit the approved finished cover. Supply each replacement verbatim; preserve proper names and avoid regenerating the subject or setting unnecessarily.

```text
Use case: text localization.
Input: <the approved cover to edit>.
Change visible copy from <source language> to <target language>.
Replacement text:
- Main headline: "<exact copy>"
- Small label: "<exact copy>"
- Note: "<exact copy>"
- Proper names to keep unchanged: "<names>"
Preserve the exact face, expression, hairstyle/headscarf, outfit, pose, accessories,
photograph, crop, aspect ratio, lighting, and graphic palette.
Adjust only lettering size, line breaks, and placement needed to fit the translation.
Remove all old-language text. Add no new claims or filler text.
Return one finished cover with no watermark or UI.
```
